# Sarembok Startup World

Canonical startup map asset path:

`/Game/Sarembok/Maps/SarembokStartup`

The binary `.umap` is intentionally generated by the checked-in Unreal Python automation rather than hand-authored outside Unreal. This keeps the level asset compatible with the exact UE 5.8 editor that owns it.

## Generate

Run `Tools/UE/CreateSarembokStartupWorld.py` from the UE 5.8 Python environment.

The script creates and saves the level at the canonical path. Unreal Engine 5.8 exposes `LevelEditorSubsystem.new_level()` and `save_current_level()` for this workflow.

## Design contract

- The map is Sarembok-owned, not `/Engine/Maps/Entry`.
- The map must remain lightweight on the Intel Iris Xe development baseline.
- MetaHuman/avatar assets are resolved as a separate layer.
- Missing avatar assets must never prevent the world from opening.
- The world is a presentation/runtime shell; Sarembok Core remains independent of Unreal.
