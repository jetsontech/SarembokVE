# SAREMBOK PROGRAM GOVERNANCE

This directory establishes the initial governance and engineering record for Sarembok VE.

## Canonical documents
- `Architecture/MASTER_BLUEPRINT.md`
- `Governance/CONSTITUTION.md`
- `Engineering/Ledger/`
- `Engineering/Capability/CAPABILITY_LEDGER.md`
- `Engineering/Capability/AGENTIC_HORIZON_FRAMEWORK.md`
- `Engineering/Roadmap/MASTER_ROADMAP.md`

## Operating rule
The Git repository contains the canonical, version-controlled copies. Decisions are added as EDRs; superseding decisions reference prior EDRs rather than silently rewriting history.

## Versioning
Use semantic/document versions for major blueprint changes. Keep dated EDRs immutable after acceptance except for metadata corrections.
