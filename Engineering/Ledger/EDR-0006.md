# EDR-0006 — Sarembok Engineering Agent Execution Boundary
**Date:** 2026-08-21  
**Status:** ACCEPTED / IMPLEMENTED SLICE

## Decision

The Engineering Agent is implemented as a Sarembok-owned controller around
provider-neutral plans and explicit capability descriptors. The controller,
not a model provider, owns authorization, lifecycle state, bounded retries,
checkpoint persistence, validation, and audit evidence.

## Rationale

This reuses the existing agentic capability and execution contracts while
preventing an intelligence provider from becoming Sarembok's control plane.
Read access and validation are explicit tools. Mutating or externally
consequential tools require a separate descriptor, permission, and policy
entry; they are not inferred from plan contents.

## Consequences

The current slice can inspect a repository, run only allowlisted validation
commands, recover transient tool failures, persist checkpoints, and emit
inspectable JSONL evidence. File mutation, remote pull-request operations,
planner adapters, and runtime JSON-RPC exposure remain subsequent integrations.

## Remote operations extension

The `server.remote_terminal` capability is an explicit external-risk tool. It
requires separate connection and execution permissions, allowlisted commands,
and an operator-managed SSH credential. The connector is provider-neutral and
does not persist the VPS password supplied for interactive access.
