# EDR-0008 — Long-Horizon Execution
**Date:** 2026-08-18  
**Status:** APPROVED / ROADMAP

## Decision
Sarembok will implement durable state, checkpoints, recovery, verification and measurable task horizons for autonomous execution.

## Rationale
Long-running multi-step work requires explicit state management and error containment rather than a simple request/response loop.

## Consequences
Task execution becomes a first-class platform capability with measurable reliability and human-escalation boundaries.
