# EDR-0003 — AI-Native Computing Environment
**Date:** 2026-08-18  
**Status:** APPROVED / ROADMAP

## Decision
Sarembok will progress toward an AI-native computing environment rather than remaining only an application.

## Rationale
The target product is a complete computing experience in which intelligence, agents, memory, perception and execution are first-class concepts.

## Consequences
The current runtime and clients must be designed so they can evolve toward a Sarembok computing environment.
