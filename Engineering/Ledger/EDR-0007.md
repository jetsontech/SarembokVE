# EDR-0007 — Runtime Engineering Agent Boundary
**Date:** 2026-08-21  
**Status:** ACCEPTED / IMPLEMENTED

## Decision

Expose the Sarembok Engineering Agent through protected Runtime JSON-RPC
methods: `EngineeringAgentInfo`, `EngineeringExecutePlan`, and
`EngineeringGetExecution`. The Runtime owns authentication and transport;
the agent owns capability authorization, bounded execution, validation,
checkpointing, recovery, and audit evidence.

## Persistence and recovery

Execution checkpoints and audit records are stored as append-only JSONL files
under the existing production `/data` volume. The runtime reloads the latest
checkpoint for execution lookup after process restart. Existing SQLite/WAL
runtime state and event audit remain authoritative for platform operations.

## Security

Engineering methods are not public browser-session methods. They require the
existing runtime authentication token. Remote SSH execution is disabled unless
explicitly enabled by server configuration and still requires separate
connection and execution permissions plus an allowlisted command.

## Consequences

The agent can now be invoked through the native Sarembok runtime without a
provider dependency or parallel transport. Mutating repository tools and
human-approval workflows remain separate follow-on capabilities.
