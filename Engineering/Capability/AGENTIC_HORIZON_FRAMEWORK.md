# SAREMBOK VE — AGENTIC HORIZON FRAMEWORK

## Purpose
Measure Sarembok's ability to complete increasingly difficult autonomous tasks reliably.

## Core Metrics
- Task Horizon: human-equivalent task duration associated with a defined success threshold.
- Execution Horizon: maximum permitted active execution duration/step budget.
- Recovery Horizon: ability to recover after failures without restarting from scratch.
- Continuity Horizon: ability to resume after interruption while preserving task state.
- Multi-Agent Horizon: complexity/duration of coordinated multi-agent work.

## Evaluation Dimensions
- Success rate
- Human-equivalent task duration
- Step count
- Tool calls
- Checkpoint frequency
- Recovery count
- Verification pass rate
- Human escalation rate
- Cost
- Latency
- Security/policy violations

## Rule
Do not claim an autonomy capability from a demo alone. Maintain reproducible benchmark tasks and evidence.
